# fluxid Installation Guide

Quick reference for all installation methods across different platforms.

## 🍺 Homebrew (macOS/Linux)

```bash
brew tap steinmann321/tap
brew install fluxid
```

**Platforms**: macOS (Intel & Apple Silicon), Linux
**Setup Required**: GitHub token + homebrew-tap repository
**Status**: ✅ Configured in GoReleaser

```bash

wget https://github.com/steinmann321/fluxid-cli/releases/download/v0.1.0/fluxid_0.1.0_linux_amd64.apk
```

**Platforms**: Alpine Linux
**Setup Required**: None - auto-generated by GoReleaser
**Status**: ✅ Configured in GoReleaser

### Arch Linux (AUR)

```bash
# Using yay
yay -S fluxid-bin

# Using paru
paru -S fluxid-bin

# Manual
git clone https://aur.archlinux.org/fluxid-bin.git
cd fluxid-bin
makepkg -si
```

**Platforms**: Arch Linux, Manjaro, EndeavourOS
**Setup Required**: AUR account + SSH key
**Status**: ✅ Configured in GoReleaser (requires AUR_KEY env var)

## 📦 Direct Download (All Platforms)

Download pre-built binaries from:
https://github.com/steinmann321/fluxid-cli/releases/tag/v0.1.0

**Available archives**:
- `fluxid_0.1.0_Darwin_x86_64.tar.gz` - macOS Intel
- `fluxid_0.1.0_Darwin_arm64.tar.gz` - macOS Apple Silicon
- `fluxid_0.1.0_Linux_x86_64.tar.gz` - Linux amd64
- `fluxid_0.1.0_Linux_arm64.tar.gz` - Linux arm64
- `fluxid_0.1.0_Windows_x86_64.zip` - Windows amd64
- `fluxid_0.1.0_Windows_arm64.zip` - Windows arm64

**Installation**:
```bash
# Extract
tar xzf fluxid_*.tar.gz  # or unzip for Windows

# Move to PATH
sudo mv fluxid /usr/local/bin/  # Linux/macOS
# or move to C:\Windows\System32\  # Windows
```

## 🚀 For Release Managers

### One-Time Setup

1. **Homebrew**: Create `steinmann321/homebrew-tap` repository
2. **AUR**: Create AUR account and SSH key (optional)
3. **Chocolatey**: Create Chocolatey account and API key (optional)
4. **Environment Variables**:
   ```bash
   export GITHUB_TOKEN="ghp_..."  # Required for Homebrew
   export AUR_KEY="..."           # Optional for Arch
   export CHOCOLATEY_API_KEY="..." # Optional for Windows
   ```

### Release Command

```bash
# With all package managers
goreleaser release --clean

# Skip optional package managers
# Edit .goreleaser.yml and comment out aurs: and chocolateys: sections
```

### What Gets Published

On each release, GoReleaser will:
1. ✅ Build binaries for all platforms
2. ✅ Create .deb, .rpm, .apk packages (automatic)
3. ✅ Create GitHub release with all artifacts
4. ✅ Update Homebrew formula (if GITHUB_TOKEN set)
5. ✅ Publish to AUR (if AUR_KEY set)
6. ✅ Publish to Chocolatey (if CHOCOLATEY_API_KEY set)

## 🐛 Troubleshooting

### Package not found

- **Homebrew**: `brew update && brew tap steinmann321/tap`
- **AUR**: Wait ~15 minutes for AUR to sync after release
- **Chocolatey**: First package needs 1-3 days for moderation approval

### Permission denied

```bash
# Linux/macOS: Add sudo
sudo dpkg -i fluxid_*.deb
sudo dnf install fluxid_*.rpm

# Windows: Run as Administrator
```

### Command not found after install

```bash
# Check installation
which fluxid  # Linux/macOS
where fluxid  # Windows

# Reload shell
source ~/.zshrc  # or ~/.bashrc
```
